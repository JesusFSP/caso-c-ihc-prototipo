# Prototipo Caso C

Prototipo navegable del Caso C: compra de tickets para el comedor universitario.

## Acceso público

https://jesusfsp.github.io/caso-c-ihc-prototipo/

## Alcance

- Prototipo HTML estático publicado con GitHub Pages.
- Incluye los recorridos exploratorio y directo.
- Simula menú agotado, ticket existente, pago rechazado, pago pendiente, desconexión y pago aprobado.
- No realiza pagos reales ni conecta billeteras digitales.
- El QR y los datos de compra son demostrativos.
- No contiene un archivo nativo de Figma; los SVG, PNG, CSV y JSON están disponibles en `recursos/`.

## Ejecución local

Abrir `index.html` en un navegador o servir esta carpeta con un servidor HTTP local.

## Publicación

GitHub Pages usa la rama `master` y la carpeta raíz (`/`). El archivo `index.html` es el punto de entrada.
